# NoteApp_Practice

Exploring collaborative web development through a simple Note App.

This repository serves as a practice project for learning how frontend and backend development come together through collaboration. Rather than working individually, each contributor is responsible for a different part of the application while communicating through a REST API.

The primary objective is to experience a collaborative development workflow, understand how different technologies integrate, and practice maintaining separate responsibilities within the same project.

## Project Overview

The application is a simple Note App that allows users to create and manage notes. While the application itself is intentionally simple, the focus is on the development process, collaboration, and API integration.
